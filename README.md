# Party Order Bahi Dashboard

## Access the Dashboard

### Desktop Version
https://gauravinnnovate.github.io/party-order-bahi-data/

### Mobile Version  
https://gauravinnnovate.github.io/party-order-bahi-data/mobile.html

## Features

- 75 suppliers with 3,600+ products
- Auto-sync from Excel file on GitHub
- Create orders, generate PDFs
- Send directly to WhatsApp
- Track last ordered quantities
- Add custom products per party
- Works online and offline (data saved locally)

## Setup

1. The dashboard automatically loads your Excel file from GitHub
2. Open on any device with the links above
3. Your data syncs automatically!

## Update Your Data

1. Export your Purchase Item Register from your accounting software
2. Go to your GitHub repo
3. Replace the Excel file (keep the same filename)
4. Dashboard automatically fetches the latest on next load
